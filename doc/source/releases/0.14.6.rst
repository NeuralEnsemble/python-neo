========================
Neo 0.14.6 release notes
========================

15 October 2026

This release of Neo includes many bug fixes in various IOs with an eye to a 1.0 release.

See all `pull requests`_ included in this release and the `list of closed issues`_.


Update NumPy shaping for Neo Objects
------------------------------------
We have updated the reshaping of core Neo Objects to handle updates to NumPy object handling.


Gap Tolerance
-------------
We have been working toward a concept of gap tolerance within the code base for readers that may drop samples or have gaps during recording. Originally a few readers implemented this
feature in a reader specific manner (e.g. :code:`BlackrockIO`), but we hope to formalize this process. As another test of incorporating gap tolerance as a core feature of readers
we have implemented :code:`gap_tolerance_ms` in the :code:`NeuralynxIO` thanks to the work of Heberto Mayorquin. To read and comment on our proposal for gap tolerance please go to `gap API`_.


Documentation
-------------
We have made minor tweaks to the documentation. Most importantly we have updated the documentation about the differences in :code:`RawIO` between :code:`index`, :code:`id`, and :code:`name` as they relate to channels.


Bug fixes and improvements in IO modules
----------------------------------------
Bug fixes and/or improvements have been made to :code:`AxonIO`, :code:`NeuroexplorerIO`, :code:`BioCamIO`, :code:`NeoMatlabIO`, :code:`TdtIO`, :code:`BlackrockIO`, and :code:`NeuralynxIO`.
